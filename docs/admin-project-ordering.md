# Admin project ordering

The portfolio admin project list supports reordering projects directly in the sidebar.

- Drag the handle on a project card and drop it above or below another project.
- Use the up/down controls as a keyboard and touch-friendly fallback.
- Reordering renumbers projects automatically (`01`, `02`, `03`, ...).
- The reordered `projectDrafts` array is autosaved with the existing admin draft and is published in that order.
